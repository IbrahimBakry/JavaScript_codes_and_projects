
# freeCodeCamp JavaScript Certification — My Learning Journey

Hey! 👋 This repo is where I'm dumping all the JavaScript code I write while working through the [freeCodeCamp JavaScript Algorithms and Data Structures](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/) certification.

Nothing fancy here — just me learning JS, one lab and workshop at a time. I'll keep adding files as I go, so expect this folder to grow (currently around 20 files and counting).

## What's in here

Each file is a small standalone exercise from the freeCodeCamp curriculum. Most of them practice a specific concept — arrays, functions, loops, conditionals, objects, etc. — and each one has a short header comment at the top explaining what it's about.

A few examples of what you'll find:

- `grocery-shopping-list.js` — practicing array methods like `push`, `unshift`, `pop`, `shift`
- `lunch-menu-manager.js` — building helper functions around an array of lunch options
- ...and more to come as I keep going through the course

## Why this repo exists

Honestly, mainly for two reasons:

1. **To keep a record of what I've done.** Easy to look back and see how far I've come.
2. **To share the code** in case someone else on a similar path finds it useful or wants to compare notes.

## How to run any file

You only need Node.js installed. Then just:

```bash
node filename.js
```

Or paste the code into your browser console — most of these don't need any setup.

## Progress

I'll be updating this repo as I move through the certification. Everything here is for learning, so the code is intentionally simple and beginner-friendly — no clever tricks, no over-engineering. That's the point.
